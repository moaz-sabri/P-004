# خارطة طريق المطورين

## هدف المشروع

Studio Planner تطبيق بسيط لإدارة المشاريع والعملاء والمهام والمواعيد، يعمل محليًا دون اتصال ثم يزامن البيانات عند توفر الشبكة.

## قواعد التطوير

- ملفات المصدر في `src/` و`js/` و`css/` هي المرجع الأساسي.
- لا تعدّل الملفات المجمعة ذات الأسماء التي تحتوي على Hash يدويًا.
- أي وظيفة جديدة يجب أن تكون في وحدة مستقلة، ثم تُربط بالتطبيق عبر API واضح.
- لا تضع أسرارًا أو بيانات مستخدمين داخل Git.
- أي تعديل على قاعدة البيانات يجب أن يكون Migration قابلًا لإعادة التشغيل.
- أي تعديل على المزامنة يجب أن يضيف اختبارًا لحالة النجاح والفشل والتكرار.

## خريطة المكونات

```text
واجهة المستخدم
  ├─ js/app.js                 المتحكم العام
  ├─ js/store.js               البيانات المحلية
  ├─ js/syncManager.js         طابور ومزامنة Offline
  ├─ js/views/                 واجهات الصفحات والنوافذ
  └─ js/authManager.js         الجلسة والمصادقة

الخادم
  ├─ api/index.php             الموجه الرئيسي
  ├─ api/auth.php              التسجيل والجلسات والأدوار
  ├─ api/sync.php              المزامنة
  ├─ api/middleware.php        حراسة الطلبات
  ├─ api/authorization.php     الأدوار والصلاحيات
  └─ api/services/             منطق الأعمال القابل لإعادة الاستخدام

قاعدة البيانات
  └─ docker/mysql/init.sql     المخطط الأولي ومرجع الجداول
```

## دورة تطوير أي ميزة

1. حدد المجال: مشروع، عميل، مهمة، مستخدم، أو مزامنة.
2. أضف منطق المجال في Service أو Repository مستقل.
3. أضف تحقق المدخلات والصلاحية المناسبة.
4. اربط Endpoint أو واجهة مستقلة.
5. أضف اختبارًا.
6. شغّل `npm run preflight`.
7. راجع التغييرات ثم أنشئ Commit واضحًا.

## خارطة الطريق

### مكتمل

- Offline-first ومزامنة أساسية.
- Cookie Authentication وCSRF.
- Idempotency للمزامنة.
- أدوار وصلاحيات أولية.
- Docker للتطوير.
- اختبارات أولية وبناء Production.
- فحص تكاملي داخل Docker.

### المرحلة التالية

- اختبار E2E كامل داخل المتصفح.
- استبدال التخزين المحلي الكبير بـ IndexedDB.
- فصل API إلى Controllers وServices وRepositories.
- إضافة نظام Migrations مستقل بدل الاعتماد على Auto Migration.
- إضافة نسخ احتياطي واستعادة مجربة آليًا.

### قبل الإطلاق العام

- مراجعة XSS وCSP.
- HTTPS وPHP-FPM مضبوطين على الخادم.
- مراقبة Logs وHealth Checks.
- اختبار ضغط على بيانات كبيرة.
- سياسة خصوصية وشروط استخدام.
- مراجعة صلاحيات كل Endpoint.

### لاحقًا

- مشاركة المشاريع مع العملاء.
- مرفقات وملفات.
- تقارير PDF.
- فواتير ومدفوعات.
- تطبيق جوال.
- Multi-tenant Organizations واشتراكات.
