# 📋 مفكرة الاستوديو | Studio Planner (نظام محلي متعدد الصفحات)

نظام إدارة مشاريع وتخطيط مواعيد مصمم خصيصاً للاستوديوهات، المهندسين، ومصممي الديكور. يعمل **محلياً بالكامل 100% دون الحاجة إلى موقع إنترنت أو خادم خارجي**، ويدعم العمل عبر النقر المزدوج المباشر على الملفات (`file:///`) أو عبر خادم محلي / PWA.

---

## 📑 هيكل الصفحات والأقسام المنفصلة

تم تقسيم النظام إلى **صفحات وأقسام مستقلة ومتكاملة**، تشترك جميعها في نفس قاعدة البيانات المحلية المحدثة لحظياً (`LocalStorage`):

1. **📅 صفحة الأجندة والمواعيد (`index.html`)**:
   - شريط إحصائيات علوي لمهام اليوم، الأسبوع، والمهام المتأخرة.
   - شريط بحث فوري مع اختصار لوحة المفاتيح `/`.
   - شريط إضافة سريعة مباشر (Inline Quick-Add) لإدخال المهام بضغطة `Enter`.
   - تصنيفات المهام المتعددة مع عدّادات مباشرة.
   - تجميع المهام حسب الأيام (متأخر، اليوم، غداً، والتواريخ القادمة، والمنجز).

2. **📊 صفحة لوحة المشاريع والكانبان (`projects.html`)**:
   - متابعة المشاريع وفق 4 مراحل أساسية: **تصميم**، **موافقة العميل**، **تنفيذ**، و**تسليم**.
   - دعم كامل للسحب والإفلات (HTML5 Drag & Drop) لنقل المشاريع بين المراحل.
   - شريط تقدم ذكي يحسب نسبة إنجاز المهام لكل مشروع.
   - مؤشر زمني لتسليم المشروع (تنبيه باللون الأحمر عند التأخير، وحساب الأيام المتبقية).

3. **⚙️ صفحة إعدادات النظام والنسخ الاحتياطي (`settings.html`)**:
   - **المظهر والثيم:** التبديل الفوري بين الوضع النهاري، الليلي، أو التلقائي.
   - **التنبيهات الصوتية والمكتبية:** فحص الإذن، اختبار نغمة الاستوديو الهادئة، وإرسال إشعار تجريبي.
   - **النسخ الاحتياطي:** تصدير نسخة JSON كاملة من البيانات واستعادتها في أي وقت.
   - **إعادة الضبط:** خيار استعادة البيانات الافتراضية.

## ⚡ كيف يعمل محلياً 100% بدون إنترنت؟

1. **بدون أي قيود CORS (Zero Module CORS Restrictions)**:
   - تم بناء السكربتات بنمط (Universal Clean Architecture) لتعمل مباشرة حتى لو تم فتح الملفات عبر النقر المزدوج من مستكشف الملفات `file:///`.
2. **خطوط محلية آمنة (Offline Font Stack)**:
   - يدعم الخطوط العربية النظامية الحديثة دون توقف الواجهة في حال عدم توفر اتصال بالإنترنت.
3. **تنبيهات صوتية بدون ملفات خارجية (Web Audio API)**:
   - توليد نغمة التنبيه برمجياً داخل المتصفح مباشرة دون الحاجة لتحميل ملفات mp3 من الإنترنت.
4. **دعم كامل لـ PWA**:
   - عند تشغيله محلياً عبر خادم محلي (مثل Live Server)، يمكنك الضغط على **"📲 تثبيت التطبيق"** ليتحول إلى تطبيق مكتبي مثبت على جهازك يعمل أوفلاين.

## 📦 بناء Webpack (حزمة واحدة مع تشفير/تشويش وإصدارات جديدة)

```bash
npm install
npm run build
```

الخرج في `dist/`. تم دمج كل سكربتات JS والأنماط CSS في ملف واحد لكل صفحة (`main.<hash>.<build>.js` و `main.<hash>.<build>.css`)، مع تشويش الكود، وإصدارات (hash + رقم بناء) تتغير عند كل build.

ملاحظة: pages are now single-sourced in `src/*.html` (root .html removed). Build output `dist/*.html` is the runnable bundle, and `npm run build` also mirrors it to the project root (`/index.html`) so direct root URLs work. `sw.js` precaches only stable assets/pages; hashed JS/CSS are cached on first network fetch. Adding any `src/*.html` page is picked up automatically.

## ⌨️ اختصارات لوحة المفاتيح
- اضغط `/` للبحث السريع.
- اضغط `N` لفتح وإغلاق القائمة العائمة للإضافة السريعة.
- اضغط `Esc` لإغلاق أي نافذة منبثقة.
