# 📋 دفتر | Daftar (نظام محلي متكامل بنمط Offline-First مع Docker & MySQL)

- [مرشد المستخدم داخل التطبيق](guide.html)
- [خارطة طريق المطورين](docs/DEVELOPER_ROADMAP.md)
- [نشر الإنتاج على Nginx بدون Docker](docs/PRODUCTION_NGINX.md)

نظام إدارة مشاريع وتخطيط مواعيد ومتابعة عملاء مصمم خصيصاً للاستوديوهات، المهندسين، ومصممي الديكور. يعمل بنمط **Offline-First (100% محلياً بدون إنترنت مع مزامنة سحابية تلقائية فور توفر النت)**، ويدعم العمل في حاويات **Docker** مع خادم **Nginx** عالي الأداء، ومعالج **PHP 8.4/8.5-FPM**، وقاعدة بيانات **MySQL 8.0**، ولوحة تحكم **phpMyAdmin**.

---

## ✨ المزايا المعمارية والجديدة (Refactored Architecture)

1. **🐳 بيئة عمل Docker كاملة (Nginx + PHP 8.4/8.5-FPM + MySQL + phpMyAdmin)**:
   - خادم ويب **Nginx** خفيف وآمن يوفر ترويسات أمان متقدمة وضغط gzip.
   - معالج **PHP 8.4/8.5-FPM** لمعالجة طلبات الـ REST API.
   - خادم قاعدة بيانات **MySQL 8.0** مع تهيئة تلقائية للجداول وتخزين دائم للبيانات عبر `volumes`.
   - لوحة **phpMyAdmin** مدمجة وجاهزة على المنفذ `8081` للتحكم بقاعدة البيانات بسهولة.

2. **🔒 نظام مستخدمين وحسابات آمن (User Authentication)**:
   - تشفير كلمات المرور باستخدام معايير التشفير الآمنة (`BCRYPT` / `Argon2id`).
   - حماية الجلسات والرموز عبر Bearer Tokens (HMAC-SHA256).
   - عزل وحفظ بيانات كل مستخدم مع دعم الحساب الافتراضي (`admin` / `admin123`).

3. **📜 جدول سجل التغييرات الشامل (`change_log`)**:
   - توثيق دقيق لكل عملية (إضافة، تعديل، حذف) مع حفظ **المصدر (`online` أو `offline`)**.
   - تسجيل الطابع الزمني للعملية محلياً وعلى الخادم.
   - نافذة مخصصة لعرض وفلترة السجل الزمني وحركات المزامنة في صفحة الإعدادات.

4. **🔄 محرك المزامنة التلقائية وحسم التعارضات (Auto Sync & Conflict Resolution)**:
   - **العمل في وضع Offline**: يعمل التطبيق محلياً وبشكل طبيعي وسريع، ويخزن الحركات في طابور محلي.
   - **المزامنة فور عودة النت**: مراقبة تلقائية للاتصال ومزامنة فورية تطبق آخر تعديل زمني (Last-Write-Wins).
   - **تقرير وحسم التعارضات (Conflict Review Report)**: عند وجود حالات غير منطقية (مثل تعديل أوفلاين لعنصر محذوف على الخادم)، يظهر تنبيه مراجعة التعارضات ليختار المستخدم بنفسه:
     1. اعتماد التعديل المحلي.
     2. اعتماد تعديل الخادم.
     3. حفظ كنسخة مكررة إضافية.

5. **📅 التقويم الأسبوعي ورقم الأسبوع (Weekly Calendar)**:
   - حساب دقيق لرقم الأسبوع من السنة (مثال: الأسبوع 47).
   - شريط تصفح أسبوعي أعلى الأجندة مع أزرار التنقل (السابق / القادم / هذا الأسبوع).
   - **بداية أسبوع اختيارية وقابلة للتخصيص**: يختار المستخدم بداية الأسبوع المفضلة (السبت، الأحد، أو الاثنين) من صفحة الإعدادات أو مباشرة من شريط الأجندة.

## 🚀 تشغيل النظام عبر Docker

للنشر العام راجع [دليل النشر الإنتاجي](docs/DEPLOYMENT.md) ولا تستخدم إعدادات التطوير الافتراضية.

> تنبيه أمني: بيانات الدخول الموجودة في هذا الملف مخصصة للتطوير المحلي فقط. قبل أي نشر عام يجب تغيير كلمات مرور قاعدة البيانات ومفتاح `AUTH_SECRET`، وعدم تشغيل phpMyAdmin أو نشر منفذ MySQL للعامة.

### المتطلبات:
- تثبيت [Docker Desktop](https://www.docker.com/products/docker-desktop).

### خطوات التشغيل:
```bash
# تشغيل جميع الخدمات (Nginx, PHP-FPM, MySQL, phpMyAdmin)
docker-compose up -d --build
```

### الروابط والمنافذ:
- **التطبيق الرئيسي (Nginx Web)**: [http://localhost:8080](http://localhost:8080)
- **لوحة phpMyAdmin**: [http://localhost:8081](http://localhost:8081)
- **خادم MySQL**: المنفذ `3306`

### بيانات التطوير المحلي:
- لا يتم إنشاء حساب افتراضي أو كلمة مرور معروفة في قواعد البيانات الجديدة.
- أنشئ أول حساب من شاشة التسجيل، ولا تستخدم بيانات تطوير مشتركة في الإنتاج.
- يتم تحديد بيانات MySQL من ملف `.env` غير المتتبع في Git.
